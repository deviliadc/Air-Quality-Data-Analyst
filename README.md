# Air Quality Data Analysis Dashboard

Aplikasi web interaktif untuk menganalisis data kualitas udara (*Air Quality Data*) yang dibuat menggunakan Streamlit.

🔗 **Live App:** [air-quality-data-analyst.streamlit.app](https://air-quality-data-analyst.streamlit.app/)

---

## 🛠️ Setup Environment

### Virtual Environment (pip)
```bash
python -m venv venv
venv\Scripts\activate     # Windows
# source venv/bin/activate # Mac/Linux
pip install -r requirements.txt
```

## 🚀 Running Streamlit App
```bash
streamlit run dashboard.py
```
